Just leaving this here because I have to search and remind myself every so often:

> `Alt + n` inside nano gives you line numbers on the left.

Apparently `Alt + Shift + 3` works too, but that's a lot less memorable for me.

You can also pass a flag if you remember before editing `nano -l the_file.text` which might work better over SSH or in VMs where control keys aren't so functional.
