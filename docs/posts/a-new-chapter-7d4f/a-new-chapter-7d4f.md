*Hello world...again?*

So, my main role recently ended, and I find myself looking.

Thankfully this is the first time since transitioning into working in tech full-time (and *later* ceasing to be a stay-at-home-dad as the latest kiddo entered school) that I've been without work for more than a week or so.[^1]

Aside from applying for roles, I've been spending some time learning some new things, working on some side projects and honey-dos.

I got around to rolling some utility scripts I'd built for myself into a [PYPI package](https://pypi.org/manage/project/padeploy): [padeploy](https://github.com/toonarmycaptain/padeploy/).

I've done some cleaning up of this site, moving this blog here and automating the build using [Zensical](https://github.com/zensical/zensical). It's much easier to use than what I had before, and as a bonus comes with RSS built in.[^2] I am hoping to keep up with this better than my last effort!

Needless to say, if you hear of any me-shaped roles, please let me know!
